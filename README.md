# spring-cloud-gateway-eureka-microservices

## Project Overview

This project demonstrates a cloud-native microservices architecture using Spring Boot, Spring Cloud Gateway, and Netflix Eureka Server. The system provides centralized API routing, service discovery, and load balancing, enabling seamless communication between multiple microservices in a distributed environment.

## Features

- Centralized API Gateway using Spring Cloud Gateway
- Service Discovery with Netflix Eureka Server
- Dynamic Routing and Load Balancing
- RESTful API Communication
- Scalable and Distributed Architecture
- Comprehensive Testing Documentation

## Technology Stack

- Java 17
- Spring Boot
- Spring Cloud Gateway
- Netflix Eureka
- Maven
- REST APIs
- Postman
